# Lunaroclient

Modern Lunar Client download website with animated UI.

## Features
- Animated homepage
- Download page with multiple versions
- Modern glassmorphism design
- Smooth hover animations
- Responsive layout
- Fast static website

## Pages
- index.html → Homepage
- downloads.html → Download versions page

## Deployment
Can be deployed easily on:
- Vercel
- Netlify
- GitHub Pages
- Cloudflare Pages
